# 2026-10-20 教培双端工作台 · 大改版 + 学管端

## 背景
用户是教培校长，要求把「教师端 / 校长端」按新需求重做，并新增「学管端」三端 App。

## 关键架构决策（满足"两端互通"）
- 三端统一使用同一套 localStorage 键空间前缀 `wb_tx_`（students/courses/followups/tasks/income/expense/enrollment/refund/teachers/fbmat）。
- 部署到同一域名后，靠 `window.addEventListener('storage', ...)` 实现跨端/跨标签页实时同步（一端改数据，他端自动 refreshAll）。
- 权限分层：教师端只读学员/课表、仅打卡与写反馈、课酬只读；校长端/学管端可排课、录经营、调课酬、维护学员。
- 学管端自有待办用独立键 `wb_xg_todo`（不与三端共享）。

## 交付文件（单文件零外链、内联SVG、响应式）
- `teacher.html` 教师端：课表(上课提醒+月历课时视图)、学员(只读)、我的(课时课酬只读+退费同步)、反馈(扩充素材，无今日处理)。
- `principal.html` 校长端：经营(收入/支出分离、课时包同步学员、折线+饼图)、学员(融合生源管理:招生途径+数量+退费)、教师(课时柱状图+下发任务含全体老师+老师详情调课酬)、全校(只读课表无打卡+教师反馈提炼跟进)、排课、反馈。
- `xueguan.html` 学管端：今日课表(全师生)、排课(改课程)、学员(可维护)、跟进、续费预警、我的待办。

- 排课重做：先勾选学生 → 每人单独选消耗方式（仅列本人实际拥有的正课/任选课/押题课额度）；资料仅展示。默认课时=1。班课可多选合并一条。
- 营收拆分：校长端「学员」弹窗录新签营收（缴费+正课次数+福利→income 新签）；经营 tab 改为「续费录入」（加购正课+福利→income 续费）。
- 课消/工资：课消按人排除福利生；工资每生计（班课人头低于一对一课酬时按一对一发）。回本线去公式，只显示已上课时/差距/回本课消。
- 打卡→课消联动已验证逻辑正确（此前"课消不变"是旧 schema 的 localStorage 残留）。
- 加 schema 版本守卫（SCHEMA=4）：旧数据自动清空重灌。
- 反馈生成器改为按态度（good/mix/attn）润色自然文案，去掉"老师看好你"硬拼句。
- 删除解释性括号备注，仅保留动作指令类（"点击查看 / 调整课酬 / 退费"等）。
- Node DOM 桩冒烟 + 逻辑测试全过（打卡联动、福利扣减、反馈润色）。

## 2026-10-20 第三批反馈（入账合一 + 班型标注 + 排课修 bug + 配色）
- 数据模型重构（SCHEMA=5）：学员 `regular:{type,total,left}` + `welfare:{elective:{count,type},mock:{count,type},paper,materials:{count,desc},voucher}`。正课/福利均标注 一对一/班课。
- 营收合一：删除独立"营收录入"表单；营收只在「录入生源/课时」登记。剩余课时 = 缴费 ÷ (年级段×班型单价)，自动计入，不可手填；续费时累加。
- 报名流程去科目：录入只填 姓名/年级/家长电话/报名班型(1v1/班课)/缴费/福利；科目由老师/课程派生。
- 排课修复"选不了老师"：openCourse 打开弹窗时直接填充老师下拉（不再仅靠 tab 切换时的 fillSelects）；班型(顶部)决定每位学员可排额度（正课须匹配其包型，任选/押题须匹配福利型）。
- 课消按 course.classType 计价；福利课不计课消但计工资。每节课默认 1 课时。
- 教师端课表提醒改为"本月课时日历 · 点击日期查看当天课程"；学员列表隐藏课时/来源/福利、不显示科目；我的课酬按课程班型正确计算。
- 学管端学员列表显示剩余正课+福利余额、隐藏来源、不显示科目；添加学员改为轻量"登记"（无缴费）。
- 配色改清新薄荷绿主题（--pri:#13b89a），重要提醒（逾期/预警/退费）用浓墨重彩红/橙，非必要简约。
- Node DOM 桩测试全过：init 无异常、打卡→课消变动+按人扣正课/福利、福利课不计课消、老师下拉填充、缴费自动折算课时、render 互不调用(铁律)。

## 2026-10-20 第四批反馈（代金券/退费扣营收/录入分流/配色）
- 录入生源弹窗改为「新增生源 / 老生续费」分流：新增=录全字段+赠福利(券为赠额)；续费=下拉选学员→只读基本信息→确认报名班型+缴费金额，可勾选"使用代金券抵扣"，自动算 应收/抵扣/实收/课时。
- 代金券模型：w.voucher 为学员券余额(¥)。续费勾选时 vUsed=min(余额,缴费)，实收=应收−vUsed，余额扣减；课时按应收÷单价计算（券不增课时）。新增时券为"赠额"加到余额，不抵扣。
- 营收修正：`calcBiz` 本月营收 = Σ income.cash − Σ 本月 refund.amount；income 记录新增 cash/voucherUsed 字段（旧记录向后兼容：cash 缺省回退 amount）。收款/退费流水同列表展示，退费标"扣减营收"。
- 退费修复：此前退费不扣营收→现从本月营收扣除（实测 3165→3065，退100）。
- 学管端登记学员改为"仅录信息"（姓名/年级/电话/状态/备注），明确课时由校长录入；删除报名班型输入，regular 清零。
- 配色从清一色薄荷绿改为协调多色：靛蓝主色(--pri:#4f6ef7)+翡翠(ok)/琥珀(warn)/珊瑚(red)语义色+浅蓝灰底，清新有搭配（仿自律类 App 风格）。三端统一。
- SCHEMA 维持 5：本次为向后兼容改动，未强制清空重灌以保留历史数据（income.cash 缺省回退）。
- Node DOM 桩测试全过：铁律 render 不互调、退费扣营收、续费代金券抵扣(应收500/抵200/实收300/课时5.56/余额券0)、流水展示退费。
